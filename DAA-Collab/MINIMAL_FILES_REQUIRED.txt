ABSOLUTELY REQUIRED FILES FOR INTENT EXTRACTION INTEGRATION
================================================================

MINIMAL INTEGRATION REQUIREMENTS
---------------------------------

TIER 1 - CRITICAL (Cannot work without these):
-----------------------------------------------

1. func/state/agent_state.py
   - Defines AgentState dataclass
   - Required by intent_classification_node

2. func/nodes/intent_classification_node.py
   - Main node that integrates into LangGraph
   - Entry point for intent classification

3. utils/ML/ml_based_intent_classification/intent_classification.py
   - Core classification logic
   - Loads models, computes embeddings, runs similarity

4. utils/ML/ml_based_intent_classification/saved_models_transformer/intent_centroids.joblib
   - Pre-computed intent centroids (embeddings)
   - Generated by build_centroids_script.py

5. utils/ML/ml_based_intent_classification/saved_models_transformer/intent_classes.joblib
   - List of intent class names
   - Generated by build_centroids_script.py

6. utils/common.py
   - Text preprocessing utilities (preprocess_prompt)
   - Used by intent_classification.py

7. utils/memory/episodic.py
   - Stores user feedback and interactions
   - Creates checkpoints for memory


TIER 2 - HIGHLY RECOMMENDED (for full functionality):
-----------------------------------------------------

8. data/user_prompt_dataset/traffic_prompts_realistic_option2_FIXED.csv
   - Training data for building centroids
   - Only needed if rebuilding centroids from scratch

9. utils/ML/ml_based_intent_classification/build_centroids_script.py
   - Script to build/rebuild intent centroids
   - Only needed for initial setup or retraining

10. utils/ML/ml_based_intent_classification/incremental_centroid_update.py
    - Auto-updates centroids when new intents added
    - Optional but recommended for production


TIER 3 - OPTIONAL (nice to have):
----------------------------------

11. test.py
    - Example usage/testing script
    - Can be removed if they have their own tests

12. data/memory/episodic/checkpoints/interactions_history.jsonl
    - User feedback history
    - Will be created automatically if missing


FILES THAT CAN BE REMOVED:
---------------------------

✗ requirements.txt (use requirements_intent_extraction.txt instead)
✗ traffic_incidents_data.csv (sample data, not used by intent classification)
✗ test_queries.txt (documentation, not code dependency)
✗ .env (environment variables, they'll create their own)
✗ __pycache__/ directories (generated at runtime)

RUNTIME DEPENDENCIES (from requirements_intent_extraction.txt):
----------------------------------------------------------------
- sentence-transformers>=2.2.0  (for embeddings)
- torch>=2.0.0                  (for GPU/CPU inference)
- transformers>=4.30.0          (for HuggingFace models)
- numpy>=1.24.0                 (for array operations)
- scikit-learn>=1.3.0           (for cosine similarity)
- joblib>=1.3.0                 (for loading .joblib files)
- langgraph>=0.0.20             (for graph integration)


MODELS DOWNLOADED AT RUNTIME (first run):
------------------------------------------
- Qwen/Qwen3-Embedding-8B       (~7GB - for embeddings)
- Qwen/Qwen2.5-7B-Instruct      (~7GB - for unknown intent extraction)

Cached in: utils/ML/ml_based_intent_classification/saved_models_transformer/

1. Copy all TIER 1 files (7 files)

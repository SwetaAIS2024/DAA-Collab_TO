INTENT EXTRACTION MODULE - INTEGRATION GUIDE
=============================================

SETUP:
------
1. Install dependencies:
   pip install -r requirements_intent_extraction.txt

2. Build intent centroids (one-time):
   python utils/ML/ml_based_intent_classification/build_centroids_script.py

USAGE IN YOUR LANGGRAPH:
------------------------
from func.state.agent_state import AgentState
from func.nodes.intent_classification_node import intent_classification

# Add to your graph
from langgraph.graph import StateGraph

graph = StateGraph(AgentState)
graph.add_node("intent_classification", intent_classification)

# Example usage
state = AgentState(instruction="Show me accidents on Highway 1")
result = intent_classification(state)

# Access results
print(result.predicted_classified_intents)  # ['incident_detection', 'spatio_temporal']
print(result.intent_confidence_scores)      # {'incident_detection': 0.85, ...}
print(result.unknown_intents)               # ['new_intent'] if any detected
print(result.known_intents)                 # Known intents from model
print(result.classification_success)        # True if successful

STATE FIELDS USED:
------------------
Input:
  - instruction: str                        # User query

Output:
  - predicted_classified_intents: List[str] # Final predicted intents
  - intent_confidence_scores: Dict[str, float] # Confidence scores
  - known_intents: List[str]                # Intents matching known patterns
  - unknown_intents: List[str]              # New intents detected by LLM
  - classification_success: bool            # Success flag
  - mem_checkpoint_id: str                  # Memory checkpoint ID

CANONICAL INTENTS (10):
-----------------------
1. visualization           - Charts, graphs, plots
2. incident_detection      - Finding/detecting accidents
3. spatio_temporal         - Location & time-based analysis
4. meta_attributes         - Data attributes, severity, type
5. traffic_impact          - Traffic flow, congestion analysis
6. incident_classification - Categorizing incident types
7. traffic_anomaly         - Unusual traffic patterns
8. causal_analysis         - Root cause analysis
9. traffic_forecasting     - Predicting future traffic
10. report_generation      - Creating reports/summaries

HOW IT WORKS:
-------------
1. User query is preprocessed (lowercase, abbreviations expanded)
2. Query embedding generated using Qwen embedding model
3. Cosine similarity computed against intent centroids
4. Top N intents above threshold returned (min 3 intents)
5. If confidence is moderate, LLM extracts unknown intents
6. Results stored in memory for feedback loop

CONFIGURATION:
--------------
- Threshold: 0.45 (minimum similarity score)
- Min intents: 3 (minimum intents returned)
- Unknown extraction triggers when:
  * Top score < 0.85 OR
  * Gap between top 2 scores < 0.1 AND multiple close scores

MODELS USED:
------------
- Embedding: Qwen/Qwen3-Embedding-8B
- Unknown extraction: Qwen/Qwen2.5-7B-Instruct

MEMORY & FEEDBACK:
------------------
- User corrections stored in interactions_history.jsonl
- New intents incrementally added to centroids (auto-update)
- Centroids auto-rebuild with feedback data
- Use --include-memory flag when rebuilding:
  python build_centroids_script.py --include-memory

TESTING:
--------
See test.py for example usage:
  python DAA-Collab/test.py --instruction "Show me accidents on Highway 1"

NOTES:
------
- First run loads models (~10-15 seconds)
- Subsequent runs use cached models
- GPU recommended but CPU supported
- Thread-safe for concurrent requests
- Unknown intents require LLM call (~2-3 seconds)
- New intents are added to centroids automatically after user confirmation

REQUIREMENTS:
-------------
- Python 3.11+
- CUDA GPU recommended (CPU fallback available)
- ~8GB RAM minimum, 16GB recommended
- ~10GB disk space for models

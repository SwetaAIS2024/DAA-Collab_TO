## Overview

This system classifies user intents using a **dual-model approach**:

1. **Known Intent Classification** - Semantic similarity using Sentence Transformers
2. **Unknown Intent Extraction** - LLM-based extraction for intents not in training data, or simply the unknown intent labels

## Prerequisites

```bash
# 1. Create and activate virtual environment
python -m venv d_venv
.\d_venv\Scripts\activate  # Windows
# source d_venv/bin/activate  # Linux/Mac

# 2. Install dependencies
pip install -r DAA-Collab/requirements.txt

# 3. Download required models
python -m spacy download en_core_web_sm
```

## System Architecture

```
User Query
    ↓
[Text Preprocessing] → Clean text, extract entities
    ↓
[Semantic Classifier] → Match against known intent prototypes whichever are present in the training data
    ↓
[LLM Extractor] → Identify unknown intents (parallel execution) - again which are not present in the training data
    ↓
[Memory Storage] → Save to LangGraph episodic memory
    ↓
[Combined Output] → Known + Unknown intents with confidence scores
```

## Step-by-Step Guide

### Step 1: Train the Model (One-Time Setup)

```bash
# Basic training (original dataset only) ->>>> THIS IS NEEDED ONLY ONCE
python DAA-Collab/utils/ML/ml_based_intent_classification/standalone_training.py

# Advanced: Include validated memory interactions ->>>> WHENEVER THE USER WANTS TO INCLUDE THE MEMORY DATA FROM PAST USER EXPERIENCES.
python DAA-Collab/utils/ML/ml_based_intent_classification/standalone_training.py --include-memory
```

**What happens during training:**
- Loads training data from `DAA-Collab/data/user_prompt_dataset/user_prompts_intent_v1.csv`
- Creates semantic embeddings using Sentence Transformers
- Computes prototype vectors for each intent class
- Saves models to saved_models_transformer

**Expected output:**
```
✅ Model trained and saved
   - intent_prototypes.joblib (9 intent embeddings)
   - intent_classes.joblib (intent label list)
```

### Step 3: Use in Production (LangGraph Integration)

The intent classifier is automatically called by the LangGraph agent:

```python
# In main.py or your graph execution
from func.graph.graph_build import build_graph

# Build and compile graph
graph = build_graph()
app = graph.compile()

# Run with user query
result = app.invoke({
    "instruction": "Detect traffic anomalies in downtown",
    "file_path": "traffic_incidents_data.csv"
})

# Access results
print(result["predicted_classified_intents"])  # All intents
print(result["known_intents"])                 # Known intents only
print(result["unknown_intents"])               # Unknown intents only
```

## Troubleshooting

### Error: "Model files not found"

**Solution:** Train the model first:
```bash
python DAA-Collab/utils/ML/ml_based_intent_classification/standalone_training.py
```

### Error: "No validated interactions found"

**Cause:** Training with `--include-memory` but no interactions validated yet.

**Solution:** Either:
1. Run without `--include-memory` flag
2. Validate some interactions in memory first

### Low Confidence Scores

**Potential causes:**
- User query too different from training examples
- Ambiguous phrasing
- New domain terminology

**Solutions:**
1. Add similar examples to training dataset
2. Lower threshold temporarily
3. Use unknown intent extraction (automatic)

### Unknown Intent Extractor Not Working

**Check:**
1. LLM model loaded: Check console for "✅ Local LLM loaded (Qwen2.5-7B-Instruct)"
2. GPU/CPU memory: LLM requires ~8GB RAM/VRAM
3. Debug output: Set `debug=True` in prediction call
